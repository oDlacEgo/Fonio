# Radio Player APK

Android app for streaming online radio stations with full playlist control.

## Features
- Play online radio streams
- Add any custom stream URL
- Edit station list
- Reorder stations
- Add custom station thumbnails

## Installation
1. Download `app-release.apk`
2. Open it on your Android device
3. Allow installation from unknown sources if required
4. Install and launch

## Usage
- You can use built-in stations or add your own
- To add a station, provide a valid streaming URL
- You can customize name, image and order

## Disclaimer
This app does not host or provide radio streams.
Some default stations may use publicly available stream URLs.

The user is responsible for how they use the app and any content they access.
